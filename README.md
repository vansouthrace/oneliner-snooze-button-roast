A one-line roast of an alarm clock that rings at 6 AM on a Saturday, entered in the [Snooze Button Roast](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6) bounty on [make.fun](https://make.fun).

## The entry

> My alarm clock ratted me out at 6 AM on a Saturday — it told Monday I was awake, and Monday is already on its way.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
The program checks the line first: it must be 1–200 characters, per the
bounty gate, and it refuses to write anything outside that range.
